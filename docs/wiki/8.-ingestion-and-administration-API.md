## 8. Ingestion & Administration

> [!IMPORTANT]
> All endpoints under `/api/admin/*` and `/api/ingestion/*` require an active session with role `admin` or an authorized `Authorization: Bearer <ADMIN_SECRET>` header.

### `POST /api/ingestion/sync`
Manually triggers the ingestion poller across BMA, e-GP, and Open Data portals.

- **Request Body** *(optional)*:
  ```json
  {
    "source": "bma",
    "forceRescrape": false
  }
  ```

### `GET /api/admin/sync-health`
Returns pipeline health telemetry, last synchronization timestamps, and recent ingestion errors (`SyncError`).

### `GET /api/admin/stats`
Returns system metrics: total projects indexed, software vs. non-software ratios, extraction failure rates, and active user counts.
