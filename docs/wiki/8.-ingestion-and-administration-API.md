## 8. Ingestion & Administration API

[← Back to API Directory](API-Documentation) · [Admin Feature Details](FEAT‐06-Administration-Panel-&-Ingestion-Audit-Monitoring) · [Security Architecture](Security-Considerations)

> [!IMPORTANT]
> All endpoints under `/api/admin/*` and `/api/ingestion/*` require an active session with role `admin` or an authorized `Authorization: Bearer <ADMIN_SECRET>` header.

---

### `GET /api/admin/stats`
Returns top-level pipeline telemetry and KPI metrics: total projects indexed, software vs. non-software ratios, extraction failure counts, triage backlog, and active user counts.

- **Response (`200 OK`)**:
  ```json
  {
    "data": {
      "totalProjects": 1420,
      "softwareProjects": 380,
      "pendingTriage": 14,
      "classifiedCount": 366,
      "lastSyncTimestamp": "2026-11-25T14:30:00.000Z",
      "crawlerHealth": "healthy"
    }
  }
  ```

---

### `GET /api/admin/sync-health`
Returns pipeline health telemetry, last synchronization timestamps per data source (BMA, e-GP, Data.go.th), and error statistics from `SyncError`.

---

### `GET /api/admin/projects/[id]` & `PUT /api/admin/projects/[id]`
Retrieves project details for administrative triage, or applies quick inline edits directly from the `ProjectInspectorDrawer`.

- **`PUT` Request Body**:
  ```json
  {
    "titleEn": "BMA Smart Healthcare Information System",
    "category": "Healthcare / Information Systems",
    "budget": 12500000,
    "status": "open",
    "isSoftware": true
  }
  ```
- **Response (`200 OK`)**:
  ```json
  {
    "message": "Project updated successfully",
    "data": { ... }
  }
  ```

---

### `POST /api/admin/translate`
Invokes the Google Cloud Vertex AI / Gemini translation service to translate Thai procurement titles and scope descriptions into English.

- **Request Body**:
  ```json
  {
    "text": "โครงการพัฒนาระบบคลาวด์และบริหารจัดการข้อมูลขนาดใหญ่ กรุงเทพมหานคร",
    "targetLang": "en"
  }
  ```
- **Response (`200 OK`)**:
  ```json
  {
    "translatedText": "Bangkok Metropolitan Administration Big Data Management and Cloud System Development Project",
    "cached": false
  }
  ```

---

### `GET /api/admin/classification-queue`
Returns projects flagged for low AI confidence or borderline software relevance awaiting administrative verification.

---

### `POST /api/admin/classify-bulk`
Triggers bulk re-classification of flagged projects using specified AI providers.

---

### `GET /api/admin/dlq`
Queries the Dead Letter Queue (`SyncError`) for failed PDF extractions, third-party timeouts, and schema validation failures.

---

### `GET /api/admin/users` & `PUT /api/admin/users`
Administrative interface to view registered users, change roles (`user` ↔ `admin`), or suspend accounts.

---

### `POST /api/ingestion/sync`
Manually triggers the ingestion poller across external government sources.

- **Request Body** *(optional)*:
  ```json
  {
    "source": "bma",
    "forceRescrape": false
  }
  ```

---

### `POST /api/ingestion/discover`
Executes discovery spiders against government portals to detect newly published procurement notices.
- **Authentication**: Strict `requireAdmin()` check (T-06).
