## 1. Procurement Opportunities & Projects

### `GET /api/projects`
Retrieves a paginated list of active software procurement tenders with multi-attribute filtering.

- **Access**: Public
- **Query Parameters**:
  - `search` *(string, optional)*: Keyword query matching title, department, or scope.
  - `category` *(string, optional)*: `Website` | `Mobile App` | `AI` | `Database` | `Information Systems` | `Software Maintenance`.
  - `department` *(string, optional)*: Specific BMA agency or ministry name.
  - `budget` *(string, optional)*: Budget bracket (`under5m`, `5to10`, `10to20`, `above20m`).
  - `deadline` *(string, optional)*: Urgency bracket (`within7`, `within30`, `moreThan30`).
  - `page` *(integer, optional, default: 1)*: Page number.
  - `limit` *(integer, optional, default: 10)*: Results per page (max: 50).
  - `sortBy` *(string, optional, default: deadline)*: `deadline` | `budget` | `createdAt`.
  - `order` *(string, optional, default: asc)*: `asc` | `desc`.

#### Example Response (`200 OK`):

### `GET /api/projects/[id]`
Retrieves full details for a single procurement project, including the Five Core Business Pillars extracted from the TOR document.

- **Access**: Public
- **Path Parameters**:
  - `id` *(string, required)*: MongoDB `_id` or numeric `externalId`.

### `GET /api/projects/[id]/tech-specs`
Returns extracted technical compliance criteria, SLA requirements, and system integration specs for technical evaluation.

- **Access**: Public
- **Path Parameters**: `id` *(string, required)*

---

### `PATCH /api/projects/[id]/classification`
Allows administrative users to manually override or correct the automated AI category classification.

- **Access**: Restricted (`Admin` role)
- **Request Body**:
  ```json
  {
    "category": "AI",
    "isSoftwareRelated": true,
    "overrideReason": "Tender includes substantial custom computer vision models."
  }
  ```
