## 2. Historical Price Analysis & Benchmarks

### `GET /api/historical`
Queries historical government software contracts, computes statistical distribution quartiles, and returns agency spending aggregates.

- **Access**: Authenticated Users (`Registered User`, `Admin`)
- **Query Parameters**:
  - `category` *(string, optional)*: Filter by software category.
  - `department` *(string, optional)*: Filter by procuring agency.
  - `year` *(integer, optional)*: Award year (e.g., `2024`, `2025`).
  - `search` *(string, optional)*: Keyword query.
  - `stats` *(boolean, default: true)*: Computes Min, Q1, Median, Mean, Q3, Max, and IQR.
  - `agencies` *(boolean, default: false)*: Computes cross-agency distribution metrics.
